# Contributing

Open an issue describing the problem, expected behavior, Ubuntu version, application version, and relevant log output. Remove private paths and contact information first.

For a change, create a branch, keep network, persistence, orchestration, and UI responsibilities separate, and add regression tests for changed behavior. Run the checks in README before opening a pull request. Keep Python and Rust mode semantics consistent. Network tests must use mocks unless explicitly run as manual integration checks.

Do not commit downloaded papers, credentials, local settings, databases, build artifacts, or screenshots containing personal information. This project is not affiliated with or endorsed by arXiv.
